# Moved — MWP spec is now split by concern

**This file is a tombstone. It is no longer the spec.**

`mwp-revised.md` was originally one long file covering nine unrelated concerns, so any task that
needed one rule loaded all of them. It has been split:

| Was | Now |
|---|---|
| §1–3, §8–9 — aims, token awareness, session discipline, content quality | [principles.md](./principles.md) |
| §4–7 — CLAUDE.md, CONTEXT.md, reference file and memory tokenomics | [layers.md](./layers.md) |
| §10 — document metadata | [metadata.md](./metadata.md) |

Nothing was dropped: all headings were verified present and unduplicated across
the three files after the split.

**Start at [CONTEXT.md](./CONTEXT.md)** — it is the entry point to the whole standard.

This tombstone is kept because several skills and guides once referenced this path.
It will be deleted once nothing points here.
