# Templates Workspace

Scaffold content generated by the MWP skills when initialising a new project. Templates define the starting shape of each MWP file; skills populate them with project-specific content rather than leaving placeholders.

## What Lives Here

- CLAUDE.md.template: starter CLAUDE.md covering all seven components
- AGENTS.md.template: required cross-model adapter that points to CLAUDE.md
- GEMINI.md.template: directive, not a body — GEMINI.md must be identical to AGENTS.md, so this template says how to generate it rather than restating the prose
- agent-roles.md.template: starter role registry for agent responsibilities and boundaries
- CONTEXT.md.template: starter workspace CONTEXT.md
- skills.md.template: starter skills catalogue
- README.md.template: starter human-facing README
- memory.md.template: starter memory.md

`spec/file-set.md` requires nine leaf files; eight are templated here. **`DEVLOG.md`
has no template** — it is seeded with a single dated entry at scaffold time. If your
workspace has its own documentation-practice conventions doc, its DEVLOG format rule
lives there.

**This is the only template source.** Keep it that way — a workspace conventions doc
that carries its own copy of any of these bodies will drift the moment one is edited
and the other is not.

## Design Principles

- Templates are guides, not fill-in-the-blank forms; the init-mwp skill reads them and generates contextually accurate content, not placeholder text
- Every section in a template must map to a component defined in `spec/` — see `spec/CONTEXT.md`, and `spec/file-set.md` for which files exist at all
- Templates should reflect the ceiling sizes from the framework: CLAUDE.md template targets ~50 lines, CONTEXT.md targets ~100 lines
- Annotate each section with a comment explaining what belongs there and what the sizing rationale is

## Constraints

- Do not add sections not covered by `spec/` without updating the spec first. The spec changes first, always — a template ahead of the spec is a fork
- Template comments are for the skill to read; strip them from generated output
